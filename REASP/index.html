Filosofia

Conceptos > Codigo

REASP no es solo una herramienta. Es una filosofia de desarrollo donde el humano siempre lidera y la IA se adapta.

Contra la Inmediatez

El problema hoy no es "tener una IA". Es usar el modelo correcto, con el flujo correcto, para la tarea correcta. REASP elimina la sobrecarga de contexto y el desperdicio de tokens en tareas triviales.

Eficiencia de Contexto

Tareas simples usan 3 fases. Sistemas complejos usan 8. La complejidad se adapta, no se impone. Sin bucles infinitos, sin agentes recursivos, sin especificaciones masivas para tareas triviales.

Delegacion Consciente

7 agentes especializados, cada uno con el modelo de IA optimo para su rol. El orchestrator coordina, el builder implementa, el reviewer valida. Cada uno en su campo de excelencia.

Caracteristicas

Potencia sin complejidad

Un framework completo que transforma como interactuas con OpenCode.

Adaptive Pipeline

8 ModeProfiles predefinidos que ajustan automaticamente las fases SDD segun la complejidad de la tarea. Desde 3 fases para CRUDs hasta 8 para sistemas enterprise.

Intelligent Model Routing

Cada agente usa el modelo de IA optimo: GLM-5.1 para orquestacion, Kimi K2.6 para implementacion, DeepSeek V4 Pro para debugging y revision.

8 Specialized Agents

Un equipo completo de agentes especializados: Orchestrator, Planner, Builder, Architect, Reviewer, Debugger y Documentation. Cada uno con prompts optimizados.

Modern TUI Installer

Instalador interactivo con interfaz de terminal moderna. Configura REASP en minutos con seleccion visual de ModeProfiles y agentes.

Slash Commands

Comandos rapidos integrados en OpenCode: /sdd, /sdd-mode, /sdd-profile, /rass-setup, /reasp-setup, /share, /unshare. Gestiona perfiles, workflows y sesiones compartidas sin salir del editor.

AI Tools Programaticos

Herramientas sdd_mode_profile y rass_setup para gestion programatica de perfiles y agentes. Automatiza la configuracion desde codigo.

Soporte Multi-Proveedor

Selección explicita de proveedor en sdd_mode_profile con validacion. 4 providers preconfigurados (opencode-go, anthropic, openai, google) + opcion de custom models. 86 tests pasan.

REFI v2 · Epic + PART

Metodologia de planificacion empresarial con Epic (subsistema) y PART (15 secciones + 8 quality gates). Workflow de 3 pasadas con 2 STOP gates que esperan confirmacion del usuario antes de codigo.

ModeProfiles

8 modos para cada contexto

Desde iteraciones rapidas hasta sistemas mission-critical. REASP se adapta a tu necesidad.

ModeProfile Fases Ideal Para
RyouSet Default orchestrator → init → explore → propose → design → apply → verify → archive Flujo Ryou completo. El modo mas equilibrado para la mayoria de tareas.
Fast orchestrator → apply → verify CRUDs, UI simple, APIs rapidas. Minima sobrecarga, maxima velocidad.
Architecture orchestrator → init → explore → propose → design → apply → verify → archive Sistemas complejos, offline-first. Diseno profundo antes de implementar.
UI orchestrator → design → apply → verify MeridianUI, MAUI, Blazor, Avalonia. Enfocado en diseno e implementacion visual.
Debug orchestrator → explore → apply → verify Bugs, concurrencia, memory leaks. Exploracion profunda del problema.
Enterprise orchestrator → init → explore → propose → design → apply → verify → archive Sistemas mission-critical. Maxima rigurosidad en cada fase.
Legacy orchestrator → init → explore → propose → apply → verify Refactorizacion de codigo legacy. Exploracion cuidadosa antes de cambiar.
Minimal orchestrator → explore → apply Iteraciones rapidas, bajo consumo. Ideal para prototipos y pruebas.

Analisis

Honesto y transparente

REASP no es para todos. Aqui esta el analisis real para que tomes la decision correcta.

Ventajas

  • Adaptativo real — No fuerza 8 fases en un CRUD simple
  • Model routing inteligente — Cada tarea va al modelo optimo
  • 7 agentes especializados — No un solo agente que intenta todo
  • Instalador TUI moderno — Configuracion visual en terminal
  • Slash commands nativos — Integrados en OpenCode
  • Documentacion automatica — Markdown y HTML summaries
  • Sin bucles infinitos — Fases definidas, ejecucion controlada
  • Open Source — MIT License, codigo abierto y transparente
  • REFI v2 Compatible — Workflow de planificacion con Epic + PART, 8 quality gates mecanicos, 2 STOP gates. Backward-compatible con 4 paquetes legacy preservados.

Limitaciones

  • Curva de aprendizaje — Requiere entender ModeProfiles y fases
  • Configuracion inicial — Requiere setup de agentes y perfiles
  • Requiere OpenCode — Es un plugin de OpenCode, no funciona con otros editores IA
  • Stack .NET/C# — Optimizado para este ecosistema

Instalacion

Comienza en minutos

Instalacion global con npm. Disponible en Windows, Linux y macOS.

1

Instalar REASP globalmente

Instala el CLI reasp-cli (v1.0.1) globalmente via npm. Esto hace que el comando reasp este disponible en todo tu sistema.

bash 
npm install -g reasp-cli
2

Ejecutar el instalador TUI

Lanza el TUI interactivo para configurar REASP en tus agentes detectados (OpenCode, Claude Code, Gemini CLI, Codex, Antigravity CLI).

bash 
reasp install
3

Seleccionar agente y ModeProfile

El TUI detecta agentes instalados y te permite seleccionar el ModeProfile deseado. Tambien puedes elegir el proveedor y modelo en un flujo de 2 pasos (4 providers: opencode-go, anthropic, openai, google).

4

Verificar instalacion

Comprueba que REASP esta correctamente instalado y conectado a tu agente.

bash 
reasp status
