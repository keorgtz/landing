El Protocolo Multi-Agente
que tu Proyecto Necesita

RACSP es un protocolo transparente y nativo para desarrollo impulsado por IA. Vive dentro de cada proyecto como una carpeta .racsp/. Los agentes se auto-configuran detectando el protocolo en la raíz del proyecto. Sin wrappers, sin configuración global — solo abre tu agente y empieza.

Características

Diseñado para Agentes,
Construido para Desarrolladores

Cada característica de RACSP está pensada para eliminar fricción y maximizar la colaboración entre agentes de IA.

Auto-Detección

Los agentes detectan automáticamente la carpeta .racsp/ en la raíz del proyecto y cargan su configuración sin intervención manual.

Memoria Compartida

Sistema Brain basado en Markdown: BRAIN.md, AGENTS.md, LOCK.md y CONTEXT.md mantienen a todos los agentes sincronizados con el estado del proyecto.

Perfiles SDD por Agente

Cada agente puede tener su propio modelo y nivel de esfuerzo por fase. RyouSet de RASS es el perfil por defecto, totalmente personalizable.

7 Adaptadores

Soporta Claude, OpenCode, Gemini, Antigravity, Codex, DeepSeek y Kimi. Cada adaptador está optimizado para las capacidades específicas de su agente.

Instalador Universal

Auto-detecta el tipo de proyecto y configura los agentes automáticamente. Un solo comando y RACSP está listo para trabajar.

Comando ryou

CLI simple e intuitivo. Desinstala automáticamente el antiguo racsp-cli antes de instalar ryou-cli. Migración sin fricción.

Auto-Configuración

Cada agente lee su propia carpeta dentro de agents/ y carga su perfil SDD personalizado.

Sincronización Bidireccional

Los cambios en BRAIN.md se propagan automáticamente a todos los agentes activos.

Aislamiento Seguro

LOCK.md previene conflictos entre agentes coordinando acceso concurrente.

Cómo Funciona

Cuatro Pasos para Empezar

RACSP elimina toda la complejidad. Abre tu agente favorito y el protocolo se activa automáticamente.

01

Abre tu Agente

Abre Claude, OpenCode, Gemini, Antigravity, Codex, DeepSeek o Kimi en la carpeta raíz de tu proyecto. Sin wrappers, sin configuración global.

02

Auto-Detecta .racsp/

El agente escanea la raíz del proyecto, detecta la carpeta .racsp/ y reconoce que debe seguir el protocolo RACSP.

03

Carga Configuración

Lee el perfil SDD específico del agente desde agents/<nombre>/. Modelo, esfuerzo y fases personalizadas por agente.

04

Sigue el Protocolo

El agente accede a BRAIN.md para contexto compartido, actualiza AGENTS.md con su actividad y respeta LOCK.md para coordinación segura.

Archivos Core

Los 5 Pilares del Protocolo

Cada archivo tiene un propósito específico en el ecosistema RACSP. Juntos forman el sistema nervioso del protocolo.

RACSP.md

Protocol Manifest

Define la versión del protocolo, reglas globales y metadatos del proyecto. Es el primer archivo que lee cualquier agente al detectar .racsp/.

BRAIN.md

Shared Memory

Memoria compartida del proyecto en Markdown. Contiene contexto técnico, decisiones arquitectónicas, patrones y conocimiento acumulado.

AGENTS.md

Activity Tracker

Registro de actividad de todos los agentes. Quién hizo qué, cuándo y por qué. Mantiene trazabilidad completa de las intervenciones.

LOCK.md

State Lock

Coordina el estado actual y previene conflictos entre agentes concurrentes. Sistema de bloqueo optimista para operaciones seguras.

CONTEXT.md

Session Context

Contexto de la sesión actual. Variables temporales, estado de la conversación y datos específicos de la interacción en curso. Se limpia entre sesiones.

CLI

Comandos ryou

Una CLI simple y poderosa para gestionar todo el protocolo.

$ ryou setup

Wizard interactivo con dashboard visual. Configura el protocolo paso a paso.

$ ryou install

Instala el protocolo en el proyecto actual. Auto-detecta tipo de proyecto.

$ ryou agent <nombre>

Configura un agente específico. Crea su perfil SDD personalizado.

$ ryou sync

Sincroniza la memoria compartida (BRAIN.md) entre todos los agentes.

$ ryou diagnostics --full

Diagnóstico completo del sistema. Verifica configuración y estado de agentes.
