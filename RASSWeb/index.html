RASS (Ryou Adaptive SDD System) no es un simple script. Es un Sistema Operativo de Desarrollo IA Adaptativo diseñado para OpenCode. Olvidate de loops infinitos y agentes recursivos que gastan tokens sin sentido. RASS adapta dinámicamente la complejidad de la IA a la complejidad de tu código.

Filosofía Base

Conceptos > Código

El gran error de los sistemas IA actuales es asumir que siempre necesitás un pipeline de 10 pasos autónomos para arreglar un typo o hacer un CRUD. RASS nace de una filosofía estricta: El humano siempre lidera.

Contra la Inmediatez

No hay atajos. El aprendizaje real y el código robusto toman tiempo. RASS te da las herramientas para orquestar la arquitectura antes de escupir código.

Eficiencia de Contexto

Evitamos inyectar toda la base de código. Cada fase tiene su contexto específico y su modelo optimizado, reduciendo la alucinación y el coste.

Delegación Consciente

Nosotros dirigimos, la IA ejecuta. RASS te permite definir reglas de routing para que un modelo barato haga exploración y uno premium haga el diseño complejo.

Arquitectura

Modos y Perfiles Dinámicos

RASS desacopla QUÉ se hace (Modos) de QUIÉN lo hace (Perfiles). Todo se resuelve de forma estática en runtime sin procesos en background.

Modos SDD

Definen las fases exactas que va a ejecutar el flujo.

  • Fast: Orchestrator → Apply → Verify
  • Architecture: Orchestrator → Init → Explore → Propose → Apply → Verify → Archive
  • UI: Orchestrator → Design → Apply → Verify
  • Debug / Legacy / Enterprise / Minimal

Perfiles de IA

Mapean qué LLM se encarga de cada fase y su esfuerzo.

  • Premium: GPT-4o / Claude 3.5 Sonnet
  • Balanced: GPT-4o-mini / Gemini 1.5 Flash
  • Minimal: Gemma / Qwen / GLM
  • Modo Minimal: Ejecución rápida, ideal para iteraciones menores.

Dashboard Nativo para OpenCode

Olvidate de tocar la terminal. RASS incluye un plugin visual completamente integrado para tu IDE (compatible con OpenCode y VS Code) que se instala automáticamente.

Gestión Visual In-Session

Abrí la paleta de comandos (Ctrl+Shift+P) y tipeá RASS: Open SDD Dashboard. Se abrirá un panel donde podés:

  • Cambiar de Modo SDD y Perfil con un click de manera dinámica.
  • Crear nuevos Modos definiendo sus fases gráficamente.
  • Crear nuevos Perfiles de IA asignando modelos.
  • Visualizar exactamente el entorno que la IA está usando en tiempo real.
Análisis Objetivo

Ventajas y Desventajas

Conocé exactamente cuándo RASS es la herramienta perfecta y cuándo podrías no necesitarlo.

Ventajas

  • Ahorro extremo de tokens: Usás modelos baratos para exploración y premium solo para código complejo.
  • Cero sobreingeniería: Tareas simples corren en 2 fases, sistemas complejos corren en 7.
  • Altamente predecible: Al evitar agentes recursivos infinitos, el resultado es controlable y determinista.
  • Nativo en PowerShell: Super liviano, sin demonios consumiendo RAM.

Desventajas

  • Requiere conocimiento técnico: RASS espera que el humano guíe la arquitectura. No es "magia de 1 clic".
  • No es autónomo infinito: Si buscás un agente tipo Devin que trabaje solo 24 horas, RASS no hace eso intencionalmente.
  • Dependencia de OpenCode: Está construido específicamente para el flujo de trabajo de OpenCode y PowerShell.
Casos de Uso

Escenarios Ideales

Refactorización Legacy

Activá sdd-mode legacy + sdd-profile premium. El sistema forzará las fases de Init, Exploración y Propuesta antes de tocar una sola línea de código, evitando romper sistemas críticos.

Creación de UI con MeridianUI

Usá sdd-mode ui. RASS se saltará el boilerplate y activará la fase de Design obligatoria, forzando al modelo a usar los lineamientos de MeridianUI antes del Apply.

Trabajo Offline/Avión

Activá sdd-profile local. Todos los enrutamientos apuntarán a tu instancia local de LM Studio u Ollama, permitiéndote seguir modeando offline.

Implementación

Instalación Global y Unificada

Integración transparente con PowerShell y OpenCode. Un solo script instala el motor CLI globalmente y el Dashboard nativo en tu editor, sin dependencias externas raras.

powershell # 1. Cloná el repositorio de RASS git clone https://github.com/keorsoft/RASS.git cd RASS # 2. Ejecutá el instalador maestro pwsh .\install.ps1 # El script generará la arquitectura de /.opencode/ # y copiará automáticamente el plugin a ~/.vscode/extensions/

Uso Básico

Una vez instalado, podés cambiar dinámicamente el comportamiento de tu IA en cualquier proyecto de dos maneras:

powershell # Opción A: Mediante CLI en PowerShell sdd-mode architecture sdd-profile premium # Opción B: Mediante el Dashboard en OpenCode # Presioná Ctrl+Shift+P y ejecutá: > RASS: Open SDD Dashboard
